# KayzCharmzz

Handmade boutique site for **KayzCharmzz** — a female and Black-owned shop in Cleveland, Ohio. Tagline: *A Store With a Purpose.*

Live: [https://www.kayzcharmzz.com](https://www.kayzcharmzz.com)

Sister brands: [True Sparkle](https://www.truesparkles.com) (diamond painting kits) · [IK’s Charms & True Sparkle](https://www.ikscharmsandtwosparkles.com) (parent studio)

## What’s here

- Home, Shop, Classes, Custom, About, Contact, Shipping
- Category pages: tumblers, candles, jewelry, phone cases, pens
- Product catalog (tumblers, candles, charms, earrings, cases — no diamond kits)
- Local bag + checkout (Cleveland pickup or USPS, order emails Lana)
- Studio login to add, edit, or remove pieces and set lead time
- Family links to parent company and True Sparkle

## Run locally

```bash
npm install
npm run dev
```
